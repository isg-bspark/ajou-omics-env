# 우리 랩 분석 보고 표준 (프로즈 버전)

분석 결과를 보고할 때는 아래 **6요소를 이 순서로** 포함해 markdown 으로 작성한다.

1. **메타** — 데이터셋 · run_id · 분석일 · QC 결과 (헤더 표)
2. **Methods** — 전처리 파라미터(정규화·통합) · QC 기준(미토 %·최소세포) · DE 단위(환자) · 유의 기준(padj)
3. **결과표** — `| 세포유형 | 유의 유전자 수 | 반응군 ↑ | 비반응군 ↑ |`
4. **Cell Ontology ID** — 결과표의 각 세포유형에 병기 (OLS 로 조회)
5. **한계** — 환자 교란(반응↔환자 얽힘) · 배치보정 여부
6. **재현** — run_id · qc_passed · 기준값 · 생성시각

> 위 서식대로 **직접 작성**한다.
