# 우리 랩 보고서 표준 — 상세 명세

## 입력: `run_data.json`

```json
{
  "dataset": {"id": "1214", "출처": "...", "세포_수": 0, "샘플_수": 0, "환자_수": 0,
              "군_세포수": {"반응군": 0, "비반응군": 0}},
  "run":     {"run_id": "r_int", "normalize": true, "batch_corrected": true,
              "클러스터_수": 11, "qc_passed": true, "생성시각": "2026-09-01T10:00:00"},
  "qc":      {"미토_비율_중앙값_%": 8.1, "중앙값_유전자수": 4200, "이중체_추정_%": 5.2,
              "통과": true, "기준": {"미토_%": 20, "최소세포": 500}},
  "de":      [{"세포_유형": "CD8 T세포", "cl_id": "CL:0000625", "유의_유전자_수": 312,
               "반응군_상향": ["TCF7", "..."], "비반응군_상향": ["PDCD1", "..."]}]
}
```

- `cl_id` 는 **OLS(원격 MCP) 로 조회한 Cell Ontology ID**. 여러 개면 `"CL:0000625; 소진형 CL:0020031"` 처럼.

## 출력: 표준 보고서 6요소 (순서 고정)

1. **메타** — 데이터셋 · run_id · 분석일 · QC 결과 (헤더 표)
2. **Methods** — 전처리 파라미터 · QC 기준값 · DE 단위 · 유의 기준
3. **결과표** — 세포유형(+Cell Ontology ID) · 유의 유전자 수 · 반응군↑ · 비반응군↑
4. **Cell Ontology ID** — 결과표의 모든 세포유형에 병기 (표준 명명)
5. **한계** — 환자 교란(반응↔환자 얽힘) · 배치보정 여부
6. **재현** — run_id · qc_passed · 기준값 · 생성시각

`check_sop.py` 가 위 6요소를 검사한다.
